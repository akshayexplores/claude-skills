# Outgrow Prompt Card

*Pocket card for Acsia engineers, architects and PMs going on site or into a customer call. Rotate the focus monthly so it stays live rather than becoming wallpaper.*

---

```
┌──────────────────────────────────────────────┐
│  ACSIA · OUTGROW                             │
│  You're not selling. You're helping.         │
│                                              │
│  In any customer conversation, ask ONE:      │
│                                              │
│  ▸ "What else are you working on that we     │
│     might be able to help with?"             │
│                                              │
│  ▸ "What's going to other vendors right now  │
│     that we could take off your plate?"      │
│                                              │
│  ▸ "Which other programmes here have the     │
│     same problem?"                           │
│                                              │
│  Then, before you leave:                     │
│  ▸ "When should we pick this up again?"      │
│                                              │
│  ─────────────────────────────────────────   │
│  THIS MONTH'S DID YOU KNOW:                  │
│  [ e.g. LiLA — automates requirements        │
│    traceability, compliance checks and       │
│    code verification ]                       │
│                                              │
│  ─────────────────────────────────────────   │
│  Heard something? Text your manager on the   │
│  way to the car. That's it. You're done.     │
└──────────────────────────────────────────────┘
```

---

## Notes for whoever prints these

**Keep the ask to one question.** An engineer holding four questions asks none. One question, changed monthly, gets asked.

**"Text your manager" is deliberate.** Do not ask an engineer to open a CRM at a customer site. The manager logs it. The engineer's job ends at the text.

**Rotate the Did You Know monthly.** Set it in the Monday huddle at the start of each month. Pick it from the cross-sell map in `references/06-wallet-share.md` based on what the accounts actually buy today.

### Suggested rotation for Acsia's first six months

| Month | Did You Know focus | Best fit accounts |
|---|---|---|
| 1 | **LiLA** | Everyone — especially anywhere Acsia touches V&V |
| 2 | **Cybersecurity (ISO 21434)** | Telematics and connected programmes |
| 3 | **V&V and Test** | Cockpit / IVI accounts carrying heavy validation load |
| 4 | **Functional Safety (ISO 26262)** | ADAS/AD and EV programmes |
| 5 | **ASPICE process consulting** | Accounts mid-AUTOSAR migration |
| 6 | **LiLA again** | Revisit — awareness decays, and the story is stronger by month six |

### Card variants worth making

- **Delivery engineers** — as above, one question
- **Project managers** — add the percentage-of-business question: *"Roughly what share of your external engineering spend comes to us?"*
- **Delivery leads** — add the internal referral: *"Who runs [adjacent domain] for the other platform?"*
